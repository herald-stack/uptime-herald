# Contributing

Thank you for your interest in Uptime Herald.

## Reporting a bug or suggesting a change

Open an issue at https://issues.uptimeherald.org. For a bug, please include:

- the application version, shown at the bottom of the dashboard sidebar
- which database you use and its version
- what you expected and what happened instead
- the relevant part of your configuration, with passwords and API keys removed

## Security problems

Please do not open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).

## Pull requests

Please open an issue to discuss a change before you write code for it. Pull requests and
issues are read as time allows, and no response time is promised.
