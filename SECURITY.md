# Security Policy

## Supported versions

Only the latest release of Uptime Herald receives security fixes.

## Reporting a vulnerability

Please report security problems privately by email to
[security@uptimeherald.org](mailto:security@uptimeherald.org). Do not open a public
issue for a vulnerability.

A useful report includes:

- the Uptime Herald version
- what you found and where
- the steps to reproduce it
- the effect you think it has

Reports are read and answered as soon as possible, but no response time is promised.

## Disclosure

Please give us a reasonable amount of time to fix a problem before you make it
public.
